# The Ivory Table

**The Ivory Table** is a restaurant website project for a Nairobi-based dining establishment, designed to showcase its culinary offerings, dining experience, and brand identity through a modern digital presence.

## Overview

The project aims to create an elegant, accessible, and user-friendly platform where visitors can explore the restaurant, discover its menu, learn about its story, and connect with the establishment.

Built with Django, the application combines Python-powered backend functionality with a responsive frontend.

## Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite
- **Version Control:** Git & GitHub

## Key Objectives

- Establish a professional online presence for The Ivory Table.
- Showcase the restaurant's menu and dining experience.
- Provide visitors with essential restaurant information.
- Create a responsive and intuitive user experience.
- Implement dynamic functionality using Django.

## Project Structure

The application will follow Django's modular architecture, separating application logic, templates, static assets, and database models for maintainability and scalability.

## Getting Started

### Prerequisites

- Python 3.x
- pip
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate into the project directory:

   ```bash
   cd the-ivory-table
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment:

   **Windows:**
   ```bash
   venv\Scripts\activate
   ```

   **Linux/macOS:**
   ```bash
   source venv/bin/activate
   ```

5. Install project dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

7. Start the development server:

   ```bash
   python manage.py runserver
   ```

8. Visit `http://127.0.0.1:8000/` in your browser.

*Note: Installation instructions are subject to updates as the project develops.*
